## Publish with free GitHub Pages

This is a **website-only** repository. It contains no Swift/Xcode application source code.

To activate Pages, visit **Settings → Pages** in this repository, then choose:

1. **Source:** Deploy from a branch
2. **Branch:** `main`
3. **Folder:** `/(root)`
4. **Save**

After GitHub Pages finishes publishing, check these URLs:

- Home: https://ifollowyoufriend.github.io/audiounderlay-site/
- Support: https://ifollowyoufriend.github.io/audiounderlay-site/support.html
- Privacy policy: https://ifollowyoufriend.github.io/audiounderlay-site/privacy.html

**Note:** These are expected URLs, not verified live URLs until GitHub Pages reports successful deployment.

The policy reflects the pre-release beta and should be reviewed before App Store submission, including Apple's privacy details for third-party SDKs.
